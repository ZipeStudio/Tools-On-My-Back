v1.1.0:
### Changes
- Added an in-game editor with a live 3D preview.
  - Added per-entry NBT matching (custom name, custom_model_data, item_model).
  - Added support for adding items directly from your inventory.
  - Added profile sharing through the clipboard and chat.
  - Added preview poses, Steve/Alex skins and a cape toggle.
- The editor replaced the configuration screen, so YACL is no longer required.
- Renamed the "3D" flag to "Flip". Entries made before this version need it set again.
- Cleaned up the config file format.
- Ported to 1.21.10 and 26.2
